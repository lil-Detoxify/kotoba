## 开发和打包

仓库根目录执行：

```powershell
npm run dev:extension
npm run build:extension
```

开发预览：`http://127.0.0.1:5192/sidepanel.html` 和 `/learning.html`。页面内检索、保存和复习走真实本地数据层；账号请求通过开发代理连接现有生产接口，非虚拟账号。浏览器侧边栏和右键菜单只在扩展环境运行。

构建目录：`apps/extension/dist`，包括 manifest.json、sidepanel.html、learning.html、background.js 与本地代码和教材。Vite 仅清理扩展自己的 dist，不修改既有端的构建产物。

## 手动装载验收

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
2. 开启开发人员模式，选择「加载解压缩的扩展」，选中 `apps/extension/dist`。
3. 固定 KotoBud 图标，点击打开侧边栏。
4. 在普通 HTTP / HTTPS 网页中选中「日本人」，右键查词；检查侧边栏词头、释义、来源与收藏。
5. 收藏一词，进入复习，揭晓后评分；关闭重开，核对收藏、调度和设置仍保留。
6. 同时打开两个面板：同一卡片评分不能重复计入；失败应保留当前卡片。
7. 核对 320px 窄侧边栏、键盘导航、标准 / 减少动态及后台恢复。
8. 点击底部「词书」，选课学习、答题、评分与刷新；上一词回看不重复评分；「统计」核对三图、当前书阶段和其他书抽屉，并核对 CSV / JSON 导入。
9. 在右上角设置中用已有邮箱账号登录，核对 Web 已有教材进度；在扩展评分并同步，再到 Web 核对。断网评分、恢复网络重试，检查事件不重复。
10. 切换账号，确认收藏和学习记录隔离；游客记录只在明确合并后加入账号，失败时仍保留。

Chrome 使用 sidePanel.open() 的最低目标版本为 116。Edge 兼容以实测为准。浏览器内部页、商店页、PDF 等受保护页面不保证提供右键入口；可在侧边栏手动输入词语。
