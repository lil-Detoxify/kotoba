# 标日六册内置词书

应用在首次初始化时安装 `smartsl/biaori` 词表拆分出的六册，数据文件为 `apps/web/src/textbooks.json`，转换入口为 `scripts/build-textbooks.mjs`。每条记录只包含课次、词形、假名、中文释义和词性；源数据的音频时间未写入应用。

| 词书 | 课次 | 词数 |
| --- | ---: | ---: |
| 标日初级上 | 1–24 | 1,077 |
| 标日初级下 | 25–48 | 1,073 |
| 标日中级上 | 1–16 | 1,748 |
| 标日中级下 | 17–32 | 1,907 |
| 标日高级上 | 1–12 | 1,806 |
| 标日高级下 | 13–24 | 1,506 |

课号按源项目规则解析：`floor(code / 10000)` 是级别，`code % 100 + 1` 是课次。词形字段采用 `reading(term)` 注记；没有注记时将整段作为词形和假名。HTML 注记会被去除。相同词形和假名在同一课中保留为独立记录，以免静默改变源词表数量；本次生成结果包含 2 个重复键（各 1 个额外记录）。

内置词书使用固定的书、课和词 ID，便于未来同步。迁移标记 `textbooksVersion` 防止重复安装。迁移保留已有书籍、学习状态、日志和 `currentBookId`；空的新数据仍保留原测试词书以兼容现有验收，并将当前书切换到标日初级上。已删除的旧内置书不会因迁移重新出现。
