## 不可退让的开发门禁

- 保持 `feature/miniprogram`；不修改 `packages/` FSRS 算法及 Cloudflare 后端同步契约。
- 页面只使用小程序原生组件与 Uni API。存储经 `UniStorageAdapter` / `MiniProgramRepository`，发音经 `UniAudioPlayer`；导航只使用 `uni.navigateTo` / `uni.switchTab`。
- 不使用浏览器专属 API，不创建 CloudBase 业务数据库；业务数据后端唯一落点为 Cloudflare D1。
- 每阶段运行 `npm test`、`npm run check:cloudflare`、`npm run type-check --workspace=apps/miniprogram`、`npm run build:miniprogram`，并检查改动范围和构建包体积。验证结果必须区分模拟测试、编译验证和原生真机验收。

## 生产同步硬门禁

后续 Phase 5 必须按以下顺序实现，不得以定时器或页面卸载绕过：

`local hydrate → restore auth → cloud pull → validate payload → deterministic reconciliation → hydrate local → isSyncReady = true → allow push`

- 首次有效 Pull 成功并完成 payload 校验、确定性对齐、本地持久化之前，`isSyncReady` 始终为 `false`。
- Pull 失败、格式错误、账号切换、登录恢复期间，物理阻止全部 Push，包括自动重试、网络恢复、定时器、隐藏/卸载页面。
- 不允许用空本地快照或启动默认选书覆盖已有云端数据；区分 `currentBookIdSource: default | user`。
- 验收必须覆盖断网启动、无效 Pull、空本地/非空云端、账号切换、乱序返回、重复事件和过期写入。
- Phase 3/4 仅本地学习与教材读取，不提前接入 Push。

## Phase 5 本地认证与安全同步基础（2026-09-22）

- 接入现有 Worker 邮箱密码、邮箱验证码、会话自省和刷新接口；会话仅持久化在 `UniStorageAdapter`，断网启动保留已有会话并保持 Push 关闭。
- 实现严格同步状态机：先加载本地分区、恢复认证、完整 Pull、校验 payload、确定性合并并写回本地，最后才将 `isSyncReady` 置为 `true`。Pull 失败、坏响应、账号切换或过期异步返回都不能触发 Push。
- 出站队列按游客和用户分区，学习评分、困难词及选书设置与本地事务一起入队；队列 payload 必须通过严格校验，成功上传后只确认对应分区的条目。
- 游客学习记录采用一次性账号认领迁移。只有完整 Pull 成功并写入账号分区后才清理游客数据；同一批游客数据不能在账号 A、B 间重复继承。
- 同步对齐对事件去重后稳定排序；完整重建复习日志。旧云端缺少 `currentBookIdSource` 时不会覆盖本地用户主动选书，也不会用空启动状态覆盖已有云端进度。
- `npm test`：28 个文件、241 项通过；小程序类型检查、`check:cloudflare`、`build:miniprogram` 通过。构建产物 49 个文件，共 232,595 bytes（约 0.222 MiB），不含音频文件；源码扫描未发现浏览器专属 API 或 `vue-router`。
- 微信 `code` 换取统一 KotoBud session 仍需正式小程序 AppID、微信侧配置和 Worker 服务端换码契约。当前界面保持不可用提示，不伪造微信身份；邮箱账号已可继承既有云端数据。

## Phase 6 音频体验与包体积（2026-09-22）

- 发音继续由 `UniAudioPlayer` 直接播放 `https://kotobud.com/audio/...` 的 R2/CDN 地址；缓存未命中时保持远程流式首播，成功播放后后台预热本地缓存，下一次优先使用已校验的本地文件。
- 新增独立音频 LRU 缓存，默认上限 32 MiB / 100 条；相同 URL 并发下载去重，严格校验 HTTPS、HTTP 200、临时/保存路径和文件大小。解码失败会删除单条缓存并回退 CDN。
- 所有播放器实例共享单一音频焦点；新播放会停止旧实例并通知旧页面取消 fallback，避免页面之间反复抢回焦点。页面隐藏/卸载仍会停止并释放播放器。
- 设置页显示缓存条数与容量，并提供独立清理。清理只处理音频缓存 manifest 与保存文件，不读取或删除词书、学习进度及同步队列。
- `npm test`：29 个文件、256 项通过；小程序类型检查、`check:cloudflare`、`build:miniprogram` 通过。构建产物 50 个文件，共 240,860 bytes（约 0.23 MiB），低于 2 MiB 且不含 MP3/M4A/WAV/AAC/OGG。
- 已扫描 `apps/miniprogram/src`，未引入浏览器专属 API 或 `vue-router`。`obeyMuteSwitch: false` 为 iOS 静音兼容的代码级保障，仍需正式 AppID 与真实 iPhone 完成物理静音开关验收后才能标记真机通过。
