# KotoBud 浏览器扩展：方案与交付范围

日期：2026-10-03。目标为 Chrome / Edge 桌面版的 Manifest V3 扩展。当前本地候选为 0.2.2（学习整合进侧边栏，账号统一在设置中）；Web / 小程序为 0.7.4 待验收候选，Windows 已交付版本保持 0.7.3。

状态：底部查词 / 学习 / 生词本 / 复习四入口，完整学习在侧边栏内进行；右上角设置管理现有邮箱账号及云同步。0.2.2 交付证据见扩展 README；0.2.1 的后台无 DOM / 静态导入构建门禁继续保留。真实账号跨端往返、原生装载、右键菜单、service worker 唤醒与下载落盘仍待验收。交付和安装步骤见 [扩展 README](../../apps/extension/README.md)。

## 产品路径

### 2026-10-02 完整学习与三端查词升级

用户确认交付顺序：先完成扩展完整学习与现有账号云同步，再为 Web / 小程序添加查词搜索框。Web 在测试环境验收通过并获得用户批准后，才可打包新的 Windows 版本。当前 Windows 0.7.3 下载与安装包保留；本轮不得打包或上传 Windows 候选。

扩展 0.2.0 的目标范围：独立完整学习页、六册词书和自由选课、卡片 / 假名选义 / 汉字选音 / 听音选义 / 混合测验、新词 / 到期 / 难词、难词与忽略状态、学习统计、每日目标、CSV / JSON 自定义词书导入、现有邮箱账号及 D1 云同步。词头 ID、FSRS 和云数据契约沿用现有项目；收藏和课次学习共用单词进度。新增联网权限仅限正式 KotoBud 域名，用户点击教材发音后获取既有音频，扩展脚本继续全部本地打包。

账号数据使用固定账号分区，游客数据不自动转移。同步顺序为 Pull → 校验 → 确定性合并 → 本地原子保存 → Push；离线修改保留在持久队列，账号切换及失效异步结果不得写入另一账号。登录密码、验证码不持久化，也不向界面返回令牌。现有云协议同步教材学习进度、答题事件和账号设置；自定义词书文本不在现有云协议中，仍属于本地资源，界面应明确标记。

后续 Web / 小程序查词采用 `@jp/shared` 的统一检索规则：NFKC、假名归一化，精确 / 前缀 / 包含排序。搜索结果显示词头、读音、释义、书名与课次；加入生词本走既有状态和同步流程。小程序教材继续按需读取，不能将扩展整包词库塞进主包。

浏览日语网页 → 选中词语并右键「用 KotoBud 查词」→ 侧边栏展示释义 → 收藏 → 随手翻卡与 FSRS 复习。也可直接输入日语、读音或中文检索。

首版使用项目已有六册教材的本地词汇，保留词头、读音、词性、释义、书名与课次；明确标记「教材词库」，不宣称完整词典或句子翻译。未命中时允许用户自行填写读音与释义，作为手动词条保存。内置资源离线可用，不发送网页全文，也不记录完整浏览历史。

当前教材资源的再分发授权尚未独立证明，详见现有 `TEXTBOOK_SOURCES.md`。本轮产物供本地开发验收；商店分发前应核实数据许可或替换为可分发的词库。构建包附带 DATA-SOURCES.txt，不将项目已有数据等同于新增的授权证明。

## 界面与动效

- 侧边栏顶部：KotoBud 品牌、绿色纸感小横幅、日文「言」印章和金色星芒。
- 三个主要区域：查词、生词本、复习；底部设置入口。控件适配 320px 及更宽的侧边栏。
- 查词：清晰的检索状态、词头与读音、教材来源、收藏反馈。未命中与输入错误各有可执行下一步。
- 生词本：按本地保存状态展示词条、待复习数量和来源网站域名；支持导出本扩展备份。删除需在界面确认。
- 复习：先看词头与读音，揭晓后评分；复用 @jp/core 的 FSRS 调度，保存后再推进下一词，失败保留当前卡片。
- 设置与关于：复用浅绿横幅、编号分区和本地版本信息；标准 / 减少动态立即生效。
- GSAP 仅做 180–500ms 的入场、翻卡揭晓与状态切换；尊重系统减少动态、后台停止并销毁清理，避免长期循环。

## 架构与边界

新增独立 `apps/extension`，复用 Vue 3、GSAP、@jp/core、@jp/models 和现有教材词头处理。构建独立输出，旧端构建与生产部署不受影响。

后台 service worker 处理右键菜单与数据消息；本地 IndexedDB 在事务内更新收藏和评分，避免多个面板或重试导致重复评分。使用独立数据库 `kotobud-extension-v1`，不访问 Web 数据库或账号令牌。

当前权限为 sidePanel、contextMenus、storage 和仅 https://kotobud.com/* 的账号 / 教材音频访问；没有全网站 host 权限、常驻 content script、远程执行代码或新标签页替换。登录后学习修改进入既有同步队列，游客模式保持本地。右键查词只接收用户选中的文字与来源主机名，来源域名不上传。代码、词汇资源和 GSAP 均本地打包，符合 MV3 CSP。

Side Panel 的 open() 需要用户操作并支持 Chrome 116+，Edge 提供同类 API；实际兼容性以装载验收为准。[Chrome 文档](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[Edge 文档](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/sidebar)。
