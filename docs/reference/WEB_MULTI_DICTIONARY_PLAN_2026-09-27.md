# Web 多词典释义接入方案

调研日期：2026-09-27。状态：方案，未实施、未发布。资料初查交给 Luna，主代理核验来源与现有代码并整理结论。

## 1. 建议与目标

先建立按来源查询、折叠和排序的多词典面板，保留现有 JMdict/Tomoshi 数据，再补充独立的日语版维基词典。中文维基词典先评估日语词条覆盖；出版社辞典进入商业授权阶段。

目标是每个词都有统一的多来源查阅入口，展示实际命中的释义。不能承诺每个词都被所有词典收录。外链、词书释义、机器辅助内容不计为新增的独立出版社词典。

## 2. 当前项目基础（本轮读源码确认）

- `apps/web/src/services/dictionary.ts`：单个 provider；按词头散列获取 JSON，缓存最多八个分片，查询使用词头和读音。
- `packages/dictionary/src/index.ts`：当前 DictionaryEntry 合并中文、英文与日文解释；没有完整的来源级查询状态与版本结构。
- `apps/web/src/components/WordDefinition.vue`：已有词书释义、词典扩展、例句及 Kotobank 外链，但扩展区主要合并展示。
- `scripts/download-dictionary.mjs` / `scripts/build-dictionary.mjs`：固定版本 Tomoshi 开放数据库经校验、提取到 512 个分片。
- 本地 manifest：217,538 条基础词条，分片原始 JSON 合计 222,223,562 字节。这是当前本地快照，不能当作新资源的覆盖率或浏览器单次下载量。
- 当前来源是 JMdict 英文义项、Tomoshi 中文译释及部分日文解释；后者包括 Wiktionary 和机器辅助解释。源码与 manifest 未证明内置三省堂出版社辞典，不能沿用交接文档中的该说法。

## 3. 候选资源与接入边界

| 来源 | 价值与语言 | 接入建议 |
| --- | --- | --- |
| JMdict / EDRDG | 日英及词头、读音、词性、义项结构 | 保留为基础；使用下载数据自建查询，不增加同源网站来充当另一部词典。EDRDG 当前日文/英文数据许可为 CC BY-SA 4.0，其他语言需另核编者权利。[许可](https://www.edrdg.org/edrdg/licence.html) |
| Tomoshi 开放数据 | 中文译释、部分日文解释，以及辨析等衍生内容 | 复用现有层，注明机器辅助和 JMdict 衍生关系；新增表逐表查许可。音调、例句等不在开放包中，不能假设可取。[官方数据说明](https://github.com/tomoshi-app/tomoshi-dict-data) |
| 日语版 Wiktionary | 独立日文解释、词源、用法等，实际字段依词条而异 | 首选新增资源；从 raw ja-extract 中过滤日语条目，保留页面来源，与现有 Wiktionary 解释去重并补全。社区数据需抽样验收。[原始数据](https://kaikki.org/dictionary/rawdata.html) |
| 中文版 Wiktionary 中的日语词条 | 增加来自社区的中文解释 | 先测现有词书命中率；命中有用才接入，不能以整份中文维基数据规模声称日语覆盖。使用同一 raw 下载页的 zh-extract。 |
| Kotobank | 在原站查阅出版社释义 | 保留“前往原站”入口；其条款限制超范围复制、蓄积和商业利用，不能未经许可抓取后内嵌。[条款](https://kotobank.jp/rule/) |
| 三省堂 / 小学馆等出版社 | 大辞林、大辞泉、新明解等差异化权威解释，具体书名与版本待授权 | 商务询问 Web 展示和数据分发授权；本轮未找到可据以直接集成的公开授权 API。三省堂官方确认向其他数字产品提供内容，但这不等于开放接口。[三省堂公司资料](https://www.sanseido-publ.co.jp/company.html)、[大辞泉内容说明](https://japanknowledge.com/contents/library.html) |
| CJKI | 商业词汇数据，含中日专业术语 | 专业词补充候选，不能当作已确认的通用日汉解释库。官方提供定制数据授权，价格按需求商议。[授权](https://www.cjk.org/licensing/)、[产品目录](https://www.cjk.org/wp-content/uploads/cjki_product_list.pdf) |

注意：`kaikki.org/dictionary/Japanese/` 是英语版 Wiktionary 的日语词条，释义为英文，并非日语版。该页面的处理后数据下载已标记弃用；接入优先选择 raw 数据并固定快照、校验与版本。

维基文本复用需依页面实际许可保留署名、来源、修改与许可声明；图像和音频逐项核查，不随文本自动纳入。[Wikimedia 使用条款第 7 节](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use)

## 4. 欧路式呈现

欧路官方支持扩充词库，以及解释排序、折叠、隐藏和目录跳转。参考这些交互，不意味着获得其中词库的再分发权。[解释页设置](https://dict.eudic.net/areas/gitbook/1/shi-yong-zhi-yin/jie-shi-ye-mian-she-zhi.html)、[扩充词库](https://docs.eudic.net/1/shi-yong-zhi-yin/tian-jia-kuo-chong-ci-ku)

- 学习页仍先显示当前词书的简短释义，答题揭晓后提供“更多词典”入口，避免提前泄露答案。
- 桌面打开右侧释义面板，窄屏打开弹层；不把多部词典全部堆进学习卡片，保存与继续操作保持可达。
- 每个来源一个折叠区，标题显示来源名和释义语言；默认展开首选来源，其余显示摘要与命中状态。
- 支持排序、隐藏、记住默认展开项，以及来源目录。首期偏好保存在浏览器，跨设备同步另评估。
- 原文按来源保留，机器辅助内容明确标注；完整出版社书名与版本仅在获授权后展示。
- 加载、空结果、暂时失败分别呈现；单来源失败可单独重试，不能拖住其他来源或背词流程。

## 5. 技术接入设计

复用现有 Cloudflare Worker/R2 与字典模块，新增来源注册表、各来源适配器和聚合层；先兼容当前分片，不立即迁移全部数据存储。

- 来源注册记录：sourceId、显示名、释义语言、原始上游、衍生关系、数据版本、许可证、署名、来源 URL、是否允许缓存与分发。
- 查询结果按来源返回各自词条与状态，保留原义项编号、词性、用法和例句来源；不强行合并不同词典义项。
- 匹配优先使用词头＋读音，并保留读音和义项适用限制；词形还原、异体和近似命中作为候选明确标注。
- 同音不同字不能直接归并；也不能对日语汉字一律做中文繁简转换。以「はし」等同音词及「行く／いく／ゆく」验证。
- 每来源独立超时、缓存与负结果缓存；并行查询、逐项显示，取消已换词请求并抑制重复点击请求。
- 开放数据离线预处理后上传 R2；浏览器按需加载，不下载全部词典。仅在实际负载证明现有分片过大时，评估按词返回的小查询端点。
- 将来商业 API 密钥放 Worker 服务端；缓存期限、显示范围和下载权以合同为准。商业内容与开放衍生数据分开存储与许可声明。
- 更新采用版本化快照、校验、来源声明和可回滚发布。EDRDG 声明要求定期更新，Web 辞典服务给出的例子是至少每月更新；不能永久固定旧包。

## 6. 分阶段实施与验收

1. **覆盖评估**：对现有词书去重后的词头＋读音跑全量命中矩阵，区分独立来源与同源衍生内容；另抽查常用词、同音词、动词变形、外来词及惯用表达。报告单来源命中率、两类独立来源覆盖率、空结果与误命中，不以下载词条总数代替。
2. **首期 Web**：来源注册与聚合、已有来源分开展示、独立日语版 Wiktionary、折叠与排序、独立加载失败反馈；中文维基词典按覆盖评估决定是否加入。
3. **出版社阶段**：优先争取一部权威日汉辞典及一部日语国语辞典；先拿样本和 Web 授权报价，再决定数据包或 API。询问地域、商用、缓存、离线、例句音频、再分发和后续桌面/小程序权限。本轮不代用户联系出版方。
4. **个人词库导入**：后续可评估结构化 JSON 或用户本地词典导入；默认本地存储，限制可执行 HTML/脚本。MDX/MDD 的文件格式支持不构成词库授权，不纳入首期。

验收重点：多来源显示真实原文；同音误命中不展示；缺词如实提示；某来源断网不影响背词；切词无串词；长释义不遮挡继续按钮；版本更新可回滚；各来源署名和许可可查。

工程量初步估算：覆盖验证 1–2 个开发日，首期框架与一个新增开放来源 3–5 个开发日，数据与交互验收 1–2 个开发日；合计约 5–9 个开发日。这是未实施前估算，取决于提取质量、数据规模及覆盖结果。出版社授权周期与费用需单独询价，不能纳入确定交付承诺。

开放许可资源通常无需采购授权，但仍有工程维护、存储和请求成本。新增流量须实际测量后再报价，不能声称免费或给出无依据的月费。
