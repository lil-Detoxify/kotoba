# Web / Windows / 小程序功能与音频差异审计

审计依据：当前 `feature/miniprogram` 工作树中的实现。Windows 版由 Electron 主进程加载 Web 构建产物（`apps/windows/main.cjs`），因此页面功能以 Web renderer 为准；Windows 额外提供桌面快捷方式、安装版/便携版和桌面窗口能力。本文不推断未实际测量的资源耗时或 COS 可用性。

分类含义：

- **完全缺失**：小程序没有对应的功能入口或动作。
- **行为不同**：目标相近，但流程、数据范围或恢复方式有区别。
- **UI 明显不同**：功能基本存在，信息架构或交互呈现明显不同。
- **平台限制**：由 Web、桌面或微信运行时能力差异造成，不能直接要求外观/实现一致。

本轮改动状态：忽略词列表、学习页忽略按钮与恢复入口已接通；学习卡片改为 Web 三档，加入声线选择和答题反馈。音频 COS 全量校验和独立抽样通过后，小程序默认音频地址已切换为 COS，Cloudflare 保留为失败回退。

## 持久化和多端同步边界

- Web 的学习仓库由 IndexedDB adapter 管理；Windows Electron 载入同一 Web `dist` renderer，使用相同的页面状态和存储逻辑。Electron 的安装/便携形态属于发行差异。
- 小程序使用 `MiniProgramRepository` 按访客/用户分区保存 Data 与 queue；学习评分把 ReviewEvent 和 progress 分别写进 outbox，旗标修改则写 progress item。登录前需处理隐私授权；登录后先完成云端拉取/对齐，再进入可同步状态。
- 词书正文是按需加载：Web 词书详情时加载；小程序目录展示轻量目录、用户下载或开始学习时加载教材正文。教材已在此前发布到 COS。音频经此次全量校验后才把小程序默认基址切换到 COS，Cloudflare 仍保留原文件和失败回退。
- Web/Windows 的忽略功能早已把 `isIgnored` 作为进度字段同步；本轮的小程序 `setIgnored` 复用进度 outbox 格式并覆盖恢复为 `false`。学习页已接线完成“当前词 → 忽略 → 下一词”的 UI 流程。

### 音频来源、缓存与微信域名

- 播放顺序：所选女声 A/男声 C 对应的 **COS** 音频 → 相同路径的 **Cloudflare** 音频 → 词书自带/旧版音频。发生播放错误时展示非阻塞提示，学习评分和进度保存不受影响；Web/Windows 仍使用原来的音频逻辑。
- 预加载只覆盖当前词、下一词和下下词，最多一个在途下载；URL 去重，切换词条会替换排队，离开页面会取消在途任务。持久文件缓存上限为 **32 MiB / 100 个文件**，按最近使用时间淘汰。播放器在同一学习页复用一个原生 audio context，隐藏页面立即停止。
- 微信公众平台的 **request 合法域名** 保留教材 COS 源站；新增或确认 **downloadFile 合法域名**为 `https://kotobud-assets-1490543304.cos.ap-beijing.myqcloud.com`。Cloudflare 回退仍需 `https://kotobud.com` 合法域名。不得以关闭合法域名校验代替配置。
