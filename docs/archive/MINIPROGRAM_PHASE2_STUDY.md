# 微信小程序 Phase 2：卡片学习闭环

本次在 `feature/miniprogram` 推进卡片学习页，不代表整个 Phase 2 已交付。以交接文档最后的第 11–14 节为基线：Windows 发布基线为 0.6.0，核心 FSRS 与 Cloudflare 同步契约保持不变。

## 交付范围

- 学习卡片展示词面、假名、词性、释义与已有例句；支持点击和卡片区域横向滑动翻面，也提供明确的翻面按钮。
- 揭示答案后才能选择 FSRS 四档评分：忘记、困难、记得、简单。评分成功保存后进入下一词，重复提交被拦截，保存失败保留当前卡片供重试。
- 新学按当前词书或明确选择的课次生成队列；复习使用到期词汇，跨词书范围与复习页一致。无效课次不回退为全词库。
- 发音只通过 `UniAudioPlayer`，支持正常/慢速播放；按现有 Google WaveNet 规则计算地址，保留 `audioTerm` / `rawTerm`。演示词条主音频失败时使用现有备用录音的精确映射，不臆造路径。离开页面停止播放，卸载释放资源；取消后不会启动备用播放。
- 本地存储仅使用 `UniStorageAdapter` / `MiniProgramRepository`。写入串行化，存储失败向页面报告；读取失败或快照损坏时不以空数据覆盖原记录。
- 小程序类型配置改用工作区包所需的 bundler 解析方式，移除未安装且未使用的类型包声明。
- Storage 读取时恢复 FSRS 卡片的 `Date`；对缺少原生 `structuredClone` 的运行时提供仅覆盖领域数据的兼容层，不修改核心算法。

## 验证与真机验收

2026-09-21 本地验证：`npm test` 为 18 个文件、166 项全部通过；`npm run check:cloudflare`、`npm run build:miniprogram` 与 `npm run type-check --workspace=apps/miniprogram` 均通过。构建保留 touristappid 的统计功能提示，尚未配置正式小程序 AppID。

线上只读 HEAD 抽查：`本` 的 Google 音频、带 `rawTerm` 的 `アメリカ人` Google 音频及 `/audio/0.mp3`、`/audio/1.mp3` 均返回 200 / audio/mpeg；`私` 的 Google 路径返回 404，故补齐备用录音回退。此检查只验证资源可访问，不等同于微信设备播放验证。

微信开发者工具打开 `apps/miniprogram/dist/build/mp-weixin` 后，仍需完成以下原生运行时验收；Node 模拟测试和构建成功不能代替这些检查：

1. 小屏、横屏、大字体下检查长词、例句、四档按钮与底部安全区。
2. 点击、左右滑动均能翻面；纵向滚动、取消触摸不应误翻；播放按钮不会触发翻面。
3. 四档各评一次，返回首页观察已学数与打卡天数，重启后记录仍在；复习入口只展示到期词。
4. 连点评分只增加一条记录；模拟存储失败后卡片不前进，恢复后可重试。
5. 验证发音成功、网络失败、后台切换、返回页面、离开页面和 iOS 静音开关行为。

## 后续边界

- 当前仍以内置 48 词演示词书为数据基线；六册教材动态加载、文件系统容量方案、其余测验题型属于后续 Phase 2 工作。
- 完整学习快照仍存于单个 Storage key。错误已可见且可重试，但长期学习容量问题尚未解决，不应据此宣称全量教材离线化完成。
- 本轮不接通认证或云同步、不创建 CloudBase 集合、不进行远程部署。Phase 3 仍必须遵守 `local hydrate → restore auth → cloud pull → deterministic merge → persist → isSyncReady → push`。
- Phase 1 的独立同步队列尚未用于本轮评分；接入前必须补齐分区隔离、并发写入与学习记录/出站事件的一致持久化，禁止直接据现有队列实现启用 push。
