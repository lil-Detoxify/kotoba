## 1. smartsl/biaori：结构化首选

### 实际文件与字段

通过 Node `fetch` 抓取仓库 main 分支 ZIP 后读取原始文件；Windows `git clone` 因 schannel 凭据错误失败，未将该失败当作数据缺失。`words.json` 是 714,605 bytes 的合法 JSON 数组，共 9117 行，每行固定 5 列：

```text
[课号编码, 词性, 中文解释, 日文词/读音, [音频起始秒, 音频结束秒]]
```

实测首行是 `[0,"[名]","中国人","ちゅうごくじん(中国人)",[0.725,2.13]]`。因此可以直接转换为 `book/volume/lesson/pos/gloss/term`；音频时间列可选保留。文件本身是词条数组，没有把课文句子放在词条字段中。

仓库的 [`words.html`](https://github.com/smartsl/biaori/blob/main/words.html) 实际解码规则为：`book = floor(课号/10000)+1`，`unit = floor((课号%10000)/100)+1`，`lesson-in-unit = (课号%100)+1`。同一文件的课号编码与 104 个非空分组一一对应。

### 课文边界与许可

同仓库 [`lessons.json`](https://raw.githubusercontent.com/smartsl/biaori/main/lessons.json) 为 80 行 HTML（初级 48 课、中级 32 课），每行含“基本课文/会话”等日中句子；高级没有对应的 `lessons.json` 行。它不是本次词表导入目标，导入时应只取 `words.json`，避免把课文带入。

[`README.md`](https://raw.githubusercontent.com/smartsl/biaori/main/README.md) 说明项目用于学习“新标准日本语（第二版）”，并提到 2021-04-03 新增中级课文；还提示正版用户从 App 下载 `PEP/BiaoRi` 音频资源。仓库 [`LICENSE.txt`](https://raw.githubusercontent.com/smartsl/biaori/main/LICENSE.txt) 是 MIT，版权行写的是 `Copyright (c) 2018 Othneil Drew`。该 MIT 许可可明确覆盖仓库代码/文件的许可文本，但 README/数据文件没有逐项说明词表来源、教材授权或可再分发范围；不要仅凭 MIT 标记推断教材词条的完整授权。

每个课次是 Markdown 表格；列通常为“单词、词性、解释”两组三列，日文词常写成 `` `かな` (漢字) ``。上表“主表”统计只计表格里的词条，不计表头；由于少量行有格式差异，导入器仍应按单元格解析并记录异常，而不要仅按换行数切分。

六个文件在表格后有 `<!--more-->` 和以反引号包围的补充短语/例句式表达。实际扫描约为：初级上 475、初级下 840、中级上 1270、中级下 968、高级上 505、高级下 573 个补充项目，合计约 4631；它们不是主表词条，应作为待审核补充内容或跳过。仓库还另有四个“语法总结”文件和若干“单词积累笔记”，不能与六个词汇表混用。

### 许可、来源和质量边界

抓取到的仓库文件树没有 `README.md`、`LICENSE` 或版权声明（对 `raw/.../LICENSE` 和 `raw/.../README.md` 的请求均为 404）。因此该仓库**没有可确认的开源许可**；GitHub 上可阅读不等于允许复制、改编或发布。文件标题和 front matter 只表明作者将其整理为“新版标准日本语”词汇表，没有给出人民教育出版社或其他来源的授权证明。

这组 Markdown 很适合做结构交叉校验，但存在人工笔记的排版、释义和错字风险；例如抽查高级上第一课可见“课外社团活劫”等疑似错字。应以逐项校验、去重和质量标注为前置工作。这里仅记录可观察事实，不据此断言侵权或合法。

## 3. 导入建议（仅针对词表调查）

1. 先以 `smartsl/biaori/words.json` 做结构化原型：保留原始 `source_url`、课号编码、词性、中文解释、日文词和可选音频偏移；映射到六册 104 课时使用上表边界。
2. 用 `Japanese_Note` 的六个主表按课抽样比对日文词/中文解释，标记差异、疑似错字和缺失；不要自动吸收 `<!--more-->` 后补充短语、语法总结或课文。
3. 在产品正式携带或发布任何教材对应词表前，单独核实每个数据集的再授权条件，并保留许可和来源记录。代码 MIT、学习笔记、词表来源和教材内容是不同的判断维度。
