## 不可破坏的边界

- 同步顺序固定为 `local hydrate → restore auth → cloud pull → validate payload → deterministic reconciliation → hydrate local → isSyncReady = true → allow push`。Pull 失败、坏响应、账号切换或过期异步结果都必须阻止 Push；不得用空快照覆盖云端。
- 小程序端继续通过适配器访问平台能力；不在 `packages/` 改 FSRS 算法或更改 Cloudflare 同步契约来绕过平台问题，不创建 CloudBase 业务数据库。
- 保持合法域名校验；不要将批量音频打进主包，不泄露 AppSecret、Token 或其他凭据。
- 自动化通过、用户口头反馈、微信工具运行、真机矩阵、上传、审核、正式发布是不同证据等级，分别如实记录。
