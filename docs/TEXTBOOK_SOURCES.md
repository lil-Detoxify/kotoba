# 《新版中日交流标准日本语》六册词表来源核查

核查日期：2026-09-15。范围：初级、中级、高级各上／下册；目标是找到可以随 Kotoba Windows 安装包合法再分发、按教材课次组织的完整词表。

## 结论

本次查到官方教材与官方学习资源，也查到第三方词表项目，但**尚未找到同时满足六册完整性与教材数据明确再分发授权的来源**。这不是认定所有第三方词表违法；而是现有公开证据不足以将它们标为“已获授权”并内置发布。不要把通用 JLPT 词表、通用词典或空课次模板标为六册完整教材词书。

## 来源逐项核查

### 1. 人民教育出版社官方 APP

[官方介绍](https://ebook.pep.com.cn/lry/main/home)说明包含生词、课文、语法与同步语音，购买正版图书后通过封底激活码激活内容，并支持离线资源包。[官方帮助](https://ebook.pep.com.cn/lry/main/help)亦说明纸书激活方式。

公开介绍没有提供供第三方应用使用的开放词表 API、数据许可证或随安装包再分发授权。因此可作为正规学习入口和授权洽谈来源，不能将购买／个人访问权限直接解释为本软件的分发许可。本次没有登录、提取资源包或绕过激活。

### 2. smartsl/biaori

[仓库](https://github.com/smartsl/biaori)及其 [README](https://github.com/smartsl/biaori/blob/main/README.md)声称 words.html 可查询初、中、高级全部单词；同时指示正版用户从 APP 拷贝 PEP/BiaoRi 资源目录，并提到对正版音频进行修复。

README 声明项目使用 MIT 许可，但没有看到教材权利方针对原始词表、中文对译、音频的授权证明或独立数据许可。LICENSE.txt 的网页抓取失败，故本报告只记录 README 的许可声明，不声称已审阅该文件。功能覆盖是作者描述，尚未逐课与正版教材对照验证。

判断：有技术参考价值，但不能仅根据仓库 MIT 声明确认教材数据的再分发权。本次未复制词表或音频到产品。

### 3. fukangwei/Japanese_Note

[仓库文件列表](https://github.com/fukangwei/Japanese_Note)有初级、中级上下册词汇表以及高级词汇笔记。已打开的仓库根目录没有显示 LICENSE 文件或针对教材词表的开放许可声明。文件名存在不等于六册词条完整，未逐课核验。

判断：授权与完整性均不足以作为内置数据。GitHub 的[仓库许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)也明确，公开仓库本身不等同于开放复制、分发许可。

### 4. 通用开放词典

[Tomoshi 开放数据](https://github.com/tomoshi-app/tomoshi-dict-data)明确说明其 JMdict 衍生数据以及中文译释按所列许可开放使用。它可以继续承担应用中的通用释义功能，但不提供这六册教材的完整课次选词映射，不能代替教材词书。其具体归属及许可仍应随应用保留。

## 后续可执行路径

1. 获得权利方允许第三方导入／分发的词表及许可文本，或由用户提供自己有权使用的数据和许可范围；区分仅个人本机使用与打包分发。
2. 导入时保留册名、版本、课号、原始次序、词形、读音、词性、释义、来源及授权说明；检查六册共 104 个基本课次是否齐全，并记录逐课词数、缺失课与重复项。
3. 对教材音频、例句、封面另行确认许可；不从 APP 或非授权网站复制后直接随包分发。
4. Windows 打包可独立完成，保留现有导入能力，并清楚标明六册教材数据尚待授权来源。

以上是对本次检索证据的工程采纳判断，不是对未经核查来源的最终法律定性。
